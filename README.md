# ForeignWords — Тренажер для изучения иностранных слов на Django

Образовательный веб-сервис для изучения иностранных слов. Проект выполнен в рамках учебного курса.

## Функционал
1. **Словарь (CRUD):** 
   - Просмотр списка всех слов (Output Page 1).
   - Детальная информация о слове (Output Page 2).
   - Добавление новых слов с валидацией (Form 1).
   - Редактирование и удаление существующих записей.
2. **Интерактивная тренировка:**
   - Режим квиза: проверка перевода случайного слова.
   - Система подсчета очков через сессии.
3. **Экспорт данных:**
   - Генерация PDF-отчета со списком слов (Form 2).
   - Поддержка кириллицы и фильтрация по сложности.

## Технологии
- **Backend:** Django 4.x / 5.x
- **Frontend:** HTML5, CSS (Bootstrap 5)
- **Библиотеки:** 
  - `reportlab` (генерация PDF)
  - `pylint` (контроль качества кода)

## Запуск проекта
1. Склонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`.
3. Активируйте окружение и установите зависимости: `pip install -r requirements.txt`.
4. Примените миграции: `python manage.py migrate`.
5. Создайте суперпользователя: `python manage.py createsuperuser`.
6. Запустите сервер: `python manage.py runserver`.
